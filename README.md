# Quantum Spin Photon Interface

## Geometry-Constrained Spin–Photon Entanglement in Quantum-Dot Micropillar Cavities

Research programme investigating a charged-trion spin–photon interface
embedded in a birefringent semiconductor micropillar cavity.

### Core pipeline

3-D device geometry  
→ electromagnetic cavity parameters  
→ open-system quantum dynamics  
→ collected spin–photon state  
→ robustness and calibration

### Technical areas

- charged-trion quantum optics
- cavity QED
- open-system quantum dynamics
- QuTiP
- 3-D electromagnetic simulation
- Lumerical FDTD
- Maxwell-to-cavity-QED parameter mapping
- CUDA-Q Dynamics
- GPU ensemble simulation
- HPC
- uncertainty propagation
- parameter inference
- digital twins
- adaptive calibration
- scientific software engineering

The validated physical model remains the scientific foundation.
Acceleration, inference and agentic calibration are extensions only where
they serve a justified scientific workload.
